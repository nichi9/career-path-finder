# 🚀 Career Path Finder

## About
Career Path Finder is a responsive website that helps students explore careers, analyze skill gaps, prepare for placements, and track progress.

## Features
- 🏠 Home Dashboard
- 👤 Student Details Form
- 🎯 Career Recommendations
- 📊 Skill Gap Analysis
- 📚 Placement Checklist
- 🚀 Progress Tracking
- 📱 Mobile-Friendly Design

## Technologies
HTML, CSS, JavaScript, and Local Storage.

## How to Run
Open `index.html` in any web browser.

## Objective
To help students choose suitable careers, improve their skills, and prepare for job placements.
